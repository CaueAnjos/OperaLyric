# Markdown decks

One file is one deck. Slides are split by a line with three dashes.

---

<!-- layout: bullets; theme: Lagoon -->
# The format

- Start a slide with `# Title`
- Bullets are plain `- ` lines
- A directive comment sets layout and theme

---

> Plain Markdown works too, no directive needed.
